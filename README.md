# Brain Tumor Classification with FFNN

This repository contains code and results for Project 2 in FYS-STK3155 at UiO. We implement a feed-forward neural network (FFNN) from scratch for both regression and classification tasks.

## Structure

- `Code/`: Python files and notebooks for training and evaluation
- `results/`: Output files and figures
- `report.pdf`: Final scientific report (uploaded upon submission)
